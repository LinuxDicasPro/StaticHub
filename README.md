## 🔍 Overview

This repository contains statically linked binaries compiled using **ALPack**, for portability and ease of distribution.

- ⚙️ **All binaries are built to be static or self-contained with no external shared library dependencies.**
- ⚙️ **Intended for use in minimal, embedded, containerized environments or as a portable tool.**
- ⚙️ **Each release includes verified static binaries for supported platforms.**
- ⚙️ **Commands ready to download for Linux 64-bit.**
